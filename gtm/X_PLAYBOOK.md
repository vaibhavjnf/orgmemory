# X / launch playbook (agent-protocol-first)

ICP in public: associates and agents at 20–200 seat professional services firms. Not “AI for legal” as a category grab.

## Positioning line

Official memory for agentic teams. The file at 00:30. No ping. A receipt.

## What we never tweet

- Keystroke, screen, or “productivity scoring”
- Replacing Google Drive
- Dark HR dashboards
- “Just RAG on your corpus”

## Thread 1 — the midnight job

1. It’s 00:30. You’re drafting a rent amendment. The partner is asleep. Drive search is 40,000 `FINAL_v7` files.
2. Your agent calls OrgMemory Suggest. Ranking is not cosine. Reuse, recency, authority, project, ACL.
3. `fetch` requires a purpose. OrgMemory Seal issues an OKFP receipt. The partner was not pinged. Their laptop was off.
4. In the morning they see the OrgMemory Seal ledger: who fetched Exhibit B, why, hash, signature.
5. That’s official memory. Not a chatbot with citations.

## Thread 2 — why ChatGPT + Drive is not this

- No purpose binding
- No cryptographic receipt
- No employee-visible org event
- Similarity ≠ institutional authority
- Agents still bother humans or hallucinate the rent curve

Link `MOATS.md` / `docs/okfp.md` when we have a public site.

## Thread 3 — trust

Enrollment. Overlay. ACL inheritance. Employee-visible audits. No keylogging. Say it until GC stops flinching.

## Cadence

Ship v0 clips of: suggest → fetch → verified receipt → audit row. Demo org is Acme Legal. Do not use real client names.

## Founder replies (keep handy)

- “Can’t we build this?” — You can build RAG. You cannot casually become the org’s fetch protocol, license flags, and GC-visible ledger.
- “Is this surveillance?” — Employees see the feed. We index files they could already open. We do not watch screens.
- “Does this replace Drive?” — No. Overlay intelligence.

## Do not

- Pitch HR grading (P2, explicit policy only)
- Pitch Linux agents as endpoint monitoring
- Race on model quality — race on **officialness**
